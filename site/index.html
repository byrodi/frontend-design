Errors and feedback

A refused action or an invalid field is answered in a line reserved next to the control. Pop-up windows are not used. Press the same wrong thing twice and the line flashes and is announced both times.

A refused action

The team has 3 seats. Add a fourth, or remove one when nobody is left, and press again.

How it is built

The message element is created again on each attempt, so the CSS animation restarts and the live region speaks again. The flash changes color only and moves nothing.

function say(line, text, kind) {
  const p = document.createElement('p');
  p.className = 'fd-notice flash fd-notice--' + kind;
  p.setAttribute('role', kind === 'error' ? 'alert' : 'status');
  p.textContent = text;
  line.replaceChildren(p);
}

Layout stability

Within one screen size, nothing already on screen moves when a tab switches, a panel opens or data loads. Switch the tabs below. The panel keeps the height of its longest content, and the counter under it comes from a real layout-shift observer.

The scrollbar appears and the whole page jumps sideways.
Put scrollbar-gutter: stable on the root and on every scrolling panel.
A control that exists only in some states pushes the content below it.
Give it a slot that exists in every state, or place it in a layer.
A sidebar or a toolbar grows with a long name.
Chrome gets fixed widths. Long names end with an ellipsis and keep the full text in title.
A selected state adds a border, padding or font weight.
Every state carries the same box. Color and background draw the state.
Popovers, menus, dialogs and toasts sit in the flow.
They go into a layer and never push their siblings.
Loading swaps the content for something of another height.
Keep the size with min-height and skeleton rows of the real height. Images get width and height.
A late web font arrives with other metrics.
Use font-display: swap with a fallback tuned by size-adjust, or a system font stack.

The rodi. brand

The author's own sites, profiles and covers carry this brand. A product with its own name keeps its own logo and gets at most a small "by rodi." credit.

Rules of the wordmark

  • The period is the signature. It always takes the accent color and never matches the letters.
  • The letters are one stroke width with round caps, drawn from SVG paths. No font is needed.
  • Clear space around the wordmark is at least the height of the letter o.
  • It is never stretched, outlined, shadowed or placed on a busy photo.
  • Brand pink #d78494 is the identity color. Buttons and selection in an interface still use the UI accent #e47f93.
  • A new size or variant comes from generate.py in the brand folder. The logo is not redrawn by hand.

Rules and limits

The skill is mostly a set of decisions an agent makes before it draws anything. These are the ones it follows, and the cases where it steps back.

Interaction priorities

Interaction beats plain input.

First look for a way to choose, toggle, drag or compare with immediate feedback. Text fields stay for text, search and exact data.

Pictures beat long text.

Show the result with a real screenshot, a preview or a diagram and add a short caption. Action names, errors and values stay as text.

Nothing on screen jumps.

Within one screen size, a tab switch, an opened panel or loaded data never moves what is already there.

Every wrong move gets an answer.

Feedback stays in place, without pop-up windows, and it repeats on every attempt.

Simplicity beats feature count.

One main task per screen and one main next step. Rare settings open on demand.

Definition of done

  • It is clear what can be done here without reading long instructions.
  • A meaningful visual example stands where it explains better than a paragraph, and controls show the result right away.
  • Every state is readable without its color. A label, an icon or a sentence stands next to the bar, hatch or dashed frame.
  • The palette stays soft and text stays readable. No small white letters on light pink.
  • Controls work from the keyboard, focus is visible and targets are comfortable to tap.
  • Images have meaningful alt text, and animation respects prefers-reduced-motion.
  • On mobile there is no horizontal overflow and no hidden main action.
  • Every refused action and invalid input answers in place, each time it happens.
  • Switching tabs, opening a panel, loading data and showing a notice move nothing that was already on screen.
  • No dead buttons, no decorative charts with made-up numbers, no endless animation and no unrequested features.

When the skill steps back

  • The project already has its own design system. The skill is not applied and the agent follows that system.
  • Backend and infrastructure work is out of scope.
  • A new explicit request from the user takes priority over the style.
  • A targeted edit keeps the neighbouring patterns. There is no full redesign unless it was asked for.
  • Without a browser the agent reports that limit and does not claim visual testing.
  • The skill needs no network, and no specific MCP server or image generator.

How the agent works

  1. It looks at the project's stack, components and content.
  2. It takes the palette and scales from the design reference.
  3. It maps the tokens onto the styling system the project already uses.
  4. It builds the main scenario and checks narrow and wide screens.
